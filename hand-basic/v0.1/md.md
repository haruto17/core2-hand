# hand-basic v0.1

## 変数を定義する

「X=10」「Y="HELLO"」
「変数名=値」の形式

## 出力する

「PRINT X」「PRINT "HELLO"」
「PRINT 出力する変数 or 値」の形式

## 条件分岐

「IF X<10」「IF A=B」
「IF 条件式」の形式
比較演算子は「<」「<=」「=」の３つ
条件式が真のとき、「THEN」のあとに書かれた処理を実行する
条件式が偽のとき、「ELSE」があれば、「その後に書かれた処理を実行する」

例１：
AGE=21
IF 20<=AGE THEN PRINT "OK" ELSE PRINT "NO"
>> "OK"

例２：
NAME="JOHN"
IF NAME="RICK" THEN PRINT "OK" ELSE PRINT "NO"
>> "NO"


## ループ

「LOOP I=0 TO 10」
「LOOP 変数=初期値 TO 最終値」の形式
初期値から最終値まで変数を変化させながら、「THEN」のあとに書かれた処理を実行する

例１：
J=5
LOOP I=0 TO J THEN PRINT I
>> 0
>> 1
>> 2
>> 3
>> 4
>> 5

## 画面の初期化

「CLEAR」
画面に書かれた内容をクリアする

## カーソルの移動

「CURSOR 10,20」
「CURSOR x座標,y座標」の形式
カーソルを指定の座標に移動する
次回PRINT実行時は移動後の座標から出力される

## 待機

「WAIT 10」
「WAIT 待機秒数」の形式
指定秒数だけ待機する

## 実行する

「RUN」
これまでに書かれたプログラムを実行する

## プログラムを保存する

「SAVE 1」
「SAVE スロット番号」の形式
これまでに書かれたプログラムの内容をSDカードに保存する
スロット番号は1から100まで
保存の形式はテキストファイル。保存先はSDの「hand-basic/」ディレクトリ内部に保存
ファイルの名前は「スロット番号.txt」とする
無効な番号が指定されたときは何もしない

## 新規プログラムを作成する

「NEW」
これまでに書かれたプログラムの内容を消去し、新規プログラムを作成する

## プログラムを読み込む

「LOAD 1」
「LOAD スロット番号」の形式
スロットに保存されたプログラムを読み込む
無効な番号、プログラムが存在しないときは何もしない

## 保存したプログラムの一覧を表示する

「FILES」
SDカードに保存されているスロット番号と各プログラムの先頭行を表示する
「fn+D」「fn+X」で一覧をスクロールする
EnterまたはEscで編集画面に戻る

## 編集中のプログラムを復元する

編集中のプログラムは内部ストレージに自動保存する
再起動したときは、最後に編集中だったプログラムを自動的に復元する

## 音を鳴らす

「BEEP 440,1」
「BEEP 周波数,鳴らす秒数」の形式
指定された周波数で指定された秒数だけ音を鳴らす

## 音を止める

「MUTE」
音を鳴らすのを止める

## 乱数を取得する

「RND 10」
「RND 乱数の最大値（整数）」の形式
0から指定された値までのうち、ランダムな整数を返す

例：
X=RND 10
PRINT X
RUN
>> 5

## テキストの色を変える

「COLOR 255,255,255」
「COLOR r,g,b」の形式
「PRINT」で出力されるテキストの色を変更する
